SwiftX

Encrypted File Transfer

SwiftX is a file-transfer application for transferring files between compatible devices over a local connection. It uses AES-based encryption to protect transferred data and provides desktop and command-line versions. An Android version is coming soon.

  • Desktop
  • Command line
  • Android: coming soon
  • GitHub Releases
Download on GitHub

Features

  • AES-encrypted file transfers.
  • Support for large files.
  • Android application (coming soon).
  • Desktop graphical interface.
  • Command-line version.
  • Local-first transfer workflow without requiring cloud storage as an intermediary.
  • Transfer progress where supported by the interface.
